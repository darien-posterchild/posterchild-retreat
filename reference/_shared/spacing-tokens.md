# PosterChild Spacing & Geometry Tokens

**Source Authorities:** `reference/screens/home/` (Master Reference) & `🤖 DS – 2026 (v8.0)`

---

## 1. Global Spacing Scale

PosterChild adheres to a base-4 / base-8 linear spacing scale:

| Token Name | Value | Pixels | Common Usage |
| :--- | :--- | :--- | :--- |
| `--space-1` | `0.25rem` | `4px` | Pill padding, icon-text gap, button micro-spacing |
| `--space-2` | `0.5rem` | `8px` | Badge padding, chip gaps, small button gaps |
| `--space-3` | `0.75rem` | `12px` | Section title → content gap, card internal padding, table header padding |
| `--space-4` | `1.0rem` | `16px` | Card padding, small grid gaps, icon-box offsets |
| `--space-5` | `1.25rem` | `20px` | Metric card padding, notice card padding, header padding |
| `--space-6` | `1.5rem` | `24px` | Page section rhythm, global app edge padding, 3-column grid gaps |
| `--space-8` | `2.0rem` | `32px` | Large container padding, hero margins |
| `--space-10` | `2.5rem` | `40px` | Page bottom padding, large component separation |
| `--space-12` | `3.0rem` | `48px` | Section hero gaps, modal padding |

## 2. Layout & Shell Geometry Tokens

| Layout Token | Value | Meaning |
| :--- | :--- | :--- |
| `--app-shell-max-width` | `1728px` | Canonical desktop baseline width |
| `--product-content-max-width` | `1040px` | Master maximum width for product content |
| `--sidebar-expanded-width` | `280px` | Visual card width of expanded sidebar |
| `--sidebar-collapsed-width` | `64px` | Visual card width of collapsed sidebar |
| `--postie-docked-width` | `360px` | Docked Postie panel width |
| `--app-edge-padding` | `24px` | Outer gutter around rails and product workspace |
| `--shell-panel-radius` | `16px` | Canonical corner radius for Sidebar and Postie panels |
