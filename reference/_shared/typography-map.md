# PosterChild Master Typography Map

**Source Authorities:** `reference/screens/home/` (Master Screen Reference) & `🤖 DS – 2026 (v8.0)`

PosterChild uses a two-font typographic pairing:
- **`Fraunces`**: Editorial Serif for expressive display headers, page titles, and prominent numeric metric values.
- **`DM Sans`**: Modern Geometric Sans for interface copy, navigation, buttons, table data, and metadata.
